# CAOS-BR
Desenvolvimento do CAOS BR, um jogo multiplayer de tiro com arenas dinâmicas, combate, movimentação e sistemas próprios, desenvolvido em colaboração entre pessoas e ferramentas de IA.

## Jogar

Jogo publicado: https://yagoblox.github.io/CAOS-BR/

- Computador: WASD move, mouse mira, clique ou Espaço atira.
- Celular: joystick esquerdo move; joystick direito mira e atira.
- Modo offline contra bots disponível; o modo online depende do servidor multiplayer.
